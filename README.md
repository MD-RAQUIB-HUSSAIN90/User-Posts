# 📝 User-Posts — CRUD Web Application

A simple and interactive posts management web application built using **Node.js, Express.js, and EJS**. This project demonstrates the fundamental concepts of backend development and RESTful routing.

🌐 **Live Demo:** [View User-Posts](https://user-posts-x7k4.onrender.com/posts)

## 📌 About the Project

User-Posts is a CRUD-based web application where users can create posts, view individual posts, edit existing content, and delete posts.

This project was created as part of my backend development learning journey to practice Express.js routing, HTTP methods, server-side rendering, and form handling.

## ✨ Features

* ➕ Create new posts
* 📄 View all posts
* 🔍 View individual posts
* ✏️ Edit existing posts
* 🗑️ Delete posts
* 🧭 RESTful routing
* 🖥️ Dynamic pages rendered using EJS
* 🔄 HTTP method handling using Method-Override

## 🛠️ Technologies Used

* **Node.js** — JavaScript runtime
* **Express.js** — Backend web framework
* **EJS** — Embedded JavaScript templating
* **UUID** — Unique IDs for posts
* **Method-Override** — Support for PATCH and DELETE form requests
* **HTML & CSS** — Frontend structure and styling
* **Git & GitHub** — Version control and source code management
* **Render** — Deployment and hosting

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/MD-RAQUIB-HUSSAIN90/User-Posts.git
```

### 2. Open the project directory

```bash
cd User-Posts
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

### 5. Open the application

Visit the following URL in your browser:

http://localhost:5000/posts
